# Portafolio de Snoopy

Este es mi proyecto final para la materia de Programación IV. Consiste en un portafolio web sobre Snoopy, que empezó como una página estática (HTML y CSS) y lo convertí en una página dinámica usando PHP y MySQL.

## ¿Qué tiene la página?
- Información sobre Snoopy, sus alter egos y sus amigos.
- Una sección interactiva con un formulario para dejar notas.
- Conexión a base de datos: las notas se guardan en MySQL y aparecen publicadas automáticamente en la pantalla.
- Opción para eliminar las notas publicadas.

## Tecnologías que usé
- HTML5 y CSS3 para la estructura y el diseño.
- PHP para la lógica y conexión.
- MySQL para la base de datos.
- Servidor local XAMPP (Apache).

## Cómo probar el proyecto
Si quieres correr este proyecto en tu computadora, sigue estos pasos:

1. Descarga esta carpeta y pégala dentro de la ruta `C:\xampp\htdocs\`.
2. Abre tu panel de XAMPP y enciende Apache y MySQL.
3. Ve a `localhost/phpmyadmin` y crea una base de datos llamada `portafolio_db` (con su respectiva tabla para los comentarios).
4. Abre tu navegador web y entra a `http://localhost/Portafolio/index.php`.
